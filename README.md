# Ruta de Evacuación

Guía con el GPS del teléfono por las vías de evacuación hasta el punto de encuentro.
Funciona sin internet una vez abierta. En español, inglés, francés y portugués.

**App:** https://barbara973.github.io/
**Privacidad:** https://barbara973.github.io/privacidad.html — la app no recoge datos personales; la ubicación nunca sale del teléfono.
